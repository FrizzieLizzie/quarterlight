# Changelog

## 1.0.1 (2026-10-04)
- The break reminder now counts all screen time while VS Code is open, not only time with VS Code in front. Switching to a browser or another app no longer restarts the 20-minute clock.
- A reminder that comes due while you're in another app appears as soon as you return to VS Code.

## 1.0.0 (2026-10-03)
- Four seasonal themes: Autumn, Winter, Spring, Summer.
- Automatic season switching, with custom start dates and a southern-hemisphere option.
- Eye-comfort settings with one-click restore.
- 20-20-20 break reminder that works across several open windows.
- A command that opens the free Atkinson Hyperlegible Mono download page.
